# ADR-0001 — 以可执行证据渐进建立信任

状态：Proposed implementation / needs target-environment validation  
日期：2026-11-05

## 决策

以单一 Java 8+ Spring Boot 应用作为质量实验对象，所有生产与测试代码均编译到 Java 8。采用 Spring Boot 2.7.18（Java 8–21 官方兼容，已结束开源维护）作为旧系统兼容样例；JDK 25 只作为额外编译宿主，不宣称 Boot 2.7.18 官方支持 JDK 25 运行时。

格式使用可复用的 Eclipse XML + Spotless；静态规则先精选；架构与行为通过 ArchUnit / JUnit；例外不从原始报告中删除，而由策略适配器精确降级。测试、架构、格式和兼容门禁不降级。

Agent 可提案但不能批准自己改变规则。优先改模型和结构，其次加静态约束，再加指导；CI 与人类审查负责保护政策变更。

## 取舍

工具链版本选择 Java 8+ 可运行的兼容线，避免为使用新工具而抬高旧项目的最低 JDK。JDK 25 单独作为 compile-only 验证，完整运行矩阵覆盖 JDK 8 / 11 / 17 / 21。

引入一个 Python 标准库治理脚本，相比开发自定义 Maven 插件更透明、可测试、跨构建系统迁移。文件内容哈希对小改动敏感，这是首版保守的防扩大抑制设计，后续可研究稳定指纹而非立即复杂化。

## 未决

首次联网验证、JDK 8/25 工具链实测、服务器侧保护、告警噪声评估和真实旧模块试点。
